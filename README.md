# wotbo-site

Сайт проекта [WOTBO](https://wotbo.pro) — Windows optimization tool by oixro.

Статика без сборки и зависимостей: GitHub Pages отдаёт файлы прямо из корня ветки `main`.

## Структура

```
index.html      разметка и SEO-мета
css/style.css   стили, адаптив, анимации
js/main.js      меню, скроллспай, подгрузка версии и списка изменений
img/            скриншоты программы и иконка
CNAME           домен для GitHub Pages (wotbo.pro)
```

## Локальный запуск

```bash
python3 -m http.server 8080
# затем открыть http://localhost:8080
```

## Данные о версии и обновлениях

Версия (`ver.json`) и список изменений (`lastchange.json`) читаются из репозитория
[`oixro/WOTBO`](https://github.com/oixro/WOTBO) через `raw.githubusercontent.com`.
Формат `lastchange.json` — обычный текст, где строки могут начинаться с маркера:

- `[+]` — добавлено
- `[=]` — изменено
- `[-]` — удалено

Первая строка без маркера считается заголовком (например, `Ver 2.33`).
Если файл недоступен, сайт показывает заглушку и не ломается.

## Деплой

Любой коммит в `main` публикуется GitHub Pages автоматически.
